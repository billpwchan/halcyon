## Terrain

Mount Halcyon is [Ōlomana](https://en.wikipedia.org/wiki/Olomana), on O'ahu, scaled to 0.68 and turned to face the
harbour (`scripts/massif.mjs`). The elevation data comes from the U.S. Geological Survey 3D Elevation Program and is in
the public domain:
- USGS 1 Meter DEM, project HI_NOAAMauiOahu_2020_B20, tiles x62y237 and x63y237.
- USGS 1/3 arc-second DEM, tile n22w158, which fills a gap in the lidar survey.

## Inspiration

The benchmark this project set out to exceed was [TIDEWATER](https://x.com/dangreenheck/status/2102878170089169235)
by Dan Greenheck. Halcyon is an independent implementation. It shares no code with TIDEWATER and is not affiliated
with it.
